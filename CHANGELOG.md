# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The two entries below were written by hand; every entry above them is generated by [Release Please](https://github.com/googleapis/release-please) from the Conventional Commit titles merged into `main`.

## [0.1.1] - 2026-09-14

### Added

- A `bun run bump` script that keeps one version across `package.json`, `src-tauri/tauri.conf.json`, `Cargo.toml` and `Cargo.lock`, with a `--check` mode CI runs.
- A release workflow that tags `v<version>` on a merge into `main` and publishes the Windows installer built from that commit.

## [0.1.0] - 2026-09-14

### Added

- Hardware detection and `llama-server` runtime selection across CUDA, Vulkan, OpenVINO and CPU.
- A Hugging Face GGUF store for finding and installing models.
- A lease based model manager that shares one process between apps declaring the same model and quant.
- Native app lifecycle with Postgres, and a local API on `127.0.0.1:40999` speaking the OpenAI protocol.
- The `aias mcp` bridge and the `aias` Claude Code plugin.
- An unsigned Windows installer built by CI.
